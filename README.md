## Conventions used in every assignment repo

* **Naming:** `haas-ai-a<number>-<topic>`
* **README first:** what the project is, how to run it, key choices, evidence that it works, and known limitations
* **Evidence** (screenshots, GIFs, plots, test output) lives in a `results/` folder
* **No secrets in git:** keys stay in `.env` or `.env.local`, which `.gitignore` excludes
* **Pinned dependencies** (`requirements.txt`) so anyone can rerun the work
* **Commit messages:** one line, present tense, saying what changed and why
* **Large files** such as model checkpoints stay out of the repo
